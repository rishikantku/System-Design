Summary

What recent interviews are telling us

1 · Coding

Two to three coding rounds at Staff, medium-to-hard, with LinkedIn's classic tagged set still showing up: trees, graphs, sliding window, and design-flavoured data structures (Max Stack, All O`one, LRU/LFU). Recent first-hand reports add topological sort and hashing/rolling-hash problems.

Most common themes

  • Design-flavoured data structures (cache, stack with max, O(1) structures)
  • Trees and nested structures (Find Leaves, Nested List Weight Sum, LCA)
  • Graphs: BFS shortest path, topological ordering
  • Sliding window and two pointers on strings
  • Follow-ups about complexity, duplicates, huge inputs, and thread-safety

Common follow-ups

Interviewers push on complexity, edge cases (duplicates, empty, deep nesting), then "how would you make this thread-safe / handle a much larger input".

What looks staff-level

Staff signal is not speed — it is clean interfaces, naming the trade-off, testing out loud, and handling the production follow-up.

What to practise

  • Topological sort with cycle reporting and parallel waves
  • LRU and LFU from scratch, then thread-safe
  • Nested-structure DFS (both LinkedIn variants)
  • Rolling hash / Rabin-Karp
  • Sliding window templates
Confidence: B — the recurring set comes from aggregators; the individual 2025–2026 reports are first-hand but thin.

2 · AI Coding

LinkedIn runs a real AI-enabled coding round. Reports agree on the shape: a familiar problem, an AI assistant in the panel, and follow-ups that pivot to concurrency and production. Two platforms are reported — CoderPad with a model picker, and HackerRank with a built-in assistant.

Most common themes

  • Well-known patterns: caches (LRU/LFU), intervals, structured data processing, debug-and-extend a class
  • Three-phase arc: debug existing code → add a feature → handle edge cases and scale
  • You copy AI output in yourself; the AI cannot edit the file for you (CoderPad reports)
  • Evaluation is about prompt quality, verification, production thinking and communication
  • Concurrency is the most common pivot: thread-safety, race conditions, synchronisation

Common follow-ups

"Why did you choose this AI-generated approach over the other options?", "How would you test each change?", "If this went to production, what would you change?"

What looks staff-level

Treat the AI as a junior pair: you set the design, it types. Never paste code you cannot defend line by line.

What to practise

  • LRU then LFU-with-rank, AI-assisted, narrating every acceptance decision
  • Debug-and-extend drills on unfamiliar code
  • Interval manager class
  • Malformed-JSON tolerant parsing
  • Add thread-safety to something you just wrote, and explain the contention cost
Confidence: A/B — the round is confirmed by multiple 2026 sources including one first-hand report with exact follow-ups; exact problems vary by interviewer.

3 · System Design

LinkedIn design rounds skew product-centric (feed, PYMK, jobs, notifications, search, autosuggest) with strong infrastructure variants (rate limiter, job scheduler, Kafka-like queue, inverted index). Staff loops in India reported two design rounds.

Most common themes

  • Retrieval + ranking systems (autosuggest, PYMK, jobs)
  • Infrastructure primitives (rate limiter, scheduler, message queue, cache)
  • Search and indexing at scale (distributed inverted index)
  • Abuse / malicious traffic filtering
  • Recent LLD-flavoured prompts (calendar, ranked cache)

Common follow-ups

Partitioning, consistency, failure modes, caching, storage choice, data modelling, observability, cost, rollout, and ML/ranking trade-offs.

What looks staff-level

They listen for trade-offs stated out loud, blast radius reasoning, and evolution — one report ended early because "all the trade-offs are covered".

What to practise

  • Rate limiter (highest recency signal)
  • Job scheduler with exactly-once semantics
  • Autosuggest/typeahead backend
  • Distributed inverted index
  • Kafka-like log and consumer groups
  • Abuse interception pipeline
Confidence: B — several first-hand questions (A) plus aggregator recency labels (B/C). Treat the list as coverage, not prediction.

4 · Hiring Manager

The manager round mixes career narrative with real scenarios. The two strongest recent signals are career-progression walkthroughs and platform-migration influence at scale — both map directly onto your Isolated Cloud work. India Staff loops also carry a separate craftsmanship round.

Most common themes

  • Career progression and promotion triggers
  • Getting thousands of teams onto a platform, and handling holdouts
  • Most complex project led, with security and ownership probing
  • Conflict and disagreement in a critical project
  • Quality philosophy, code review at scale, mentoring
  • Turnaround scenarios for a neglected legacy system
